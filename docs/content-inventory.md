# Java 内容清单

实施时仓库中没有可供迁移的既有 Java Markdown 概念笔记。因此首版没有把未确认的私人笔记、课程摘录或自动生成的完整教材加入公开内容。

在作者要求继续完成剩余 OpenSpec 任务后，首版增加了一项公开资源：[dev.java Learn](../public/programming/java/fundamentals/dev-java-learn.md)。它作为 Java 基础与面向对象阶段的官方资料入口，不冒充作者已经完成的概念笔记。

后续每次迁移都应在提交前确认：

- 内容由作者主动批准公开。
- 引用资源允许公开链接或合理引用。
- 图片和附件不包含私人信息。
- 页面通过元数据、普通 Markdown、链接和资产校验。
