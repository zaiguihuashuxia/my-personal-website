# Spring Boot

本模块关注 Spring Boot 如何约定项目结构、组合依赖并根据运行环境完成自动配置，从而降低 Spring 应用的启动成本。

## 核心概念地图

- Starter 与依赖组合
- 自动配置与条件装配
- 配置文件、环境与属性绑定
- REST 接口、参数校验与异常处理
- 数据访问、事务和连接配置
- 单元测试与集成测试

## 推荐复习顺序

先从启动过程和自动配置入手，再学习 Web、数据访问和测试。遇到配置问题时，应当能够区分显式配置、约定默认值与条件装配结果。

## 快速自测

1. Spring Boot 自动配置依据哪些条件生效？
2. Starter 与普通依赖有什么区别？
3. 配置属性如何映射为类型安全的对象？
4. 单元测试和完整应用上下文测试分别适合什么场景？
