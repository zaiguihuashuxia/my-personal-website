# dev.java Learn

## 官方链接

- [Learn Java - dev.java](https://dev.java/learn/)

## 适合阶段

适合已经开始学习 Java 基础、希望用官方资料校准概念的读者，也适合在学习面向对象、集合、Stream 和 JVM 时按专题查阅。它更像持续更新的学习索引，不需要从头到尾一次读完。

## 前置知识

- 能安装并运行一个受支持的 JDK。
- 知道如何编辑、编译和运行最小 Java 程序。
- 阅读具体专题前，先具备该模块的基础词汇；例如学习 Stream 前先理解集合与 Lambda。

## 推荐理由

- 内容由 Java 官方站点维护，适合核对语言特性、工具和 API 的准确含义。
- 同时覆盖入门路径与独立专题，可以伴随本站从 Java 基础复习到 JVM 相关知识。
- 章节按问题组织，适合遇到概念盲点时定向查阅，而不是强迫自己完成一套固定课程。

## 建议学习范围

1. 初学阶段先看 *Running Your First Java Application* 和 *Getting to Know the Language*。
2. 进入面向对象模块后，重点查阅 Classes and Objects、Inheritance 与 Interfaces。
3. 学习常用 API 时，再按需阅读 Collections、Stream、I/O 和 Date Time。
4. JVM、模块和工具章节留到具备实际项目经验后专题复习。
