# 面向对象

本模块关注如何用对象表达状态、行为与协作关系，以及如何在复用、抽象和可维护性之间做选择。

## 核心概念地图

- 类、对象、字段、方法与构造过程
- 封装与访问控制
- 继承、组合与多态
- 方法重载与方法重写
- 接口与抽象类
- `Object`、`equals`、`hashCode` 与对象契约

## 关键关系

| 概念 | 主要作用 | 复习时关注 |
| --- | --- | --- |
| 封装 | 保护不变量 | 哪些状态不应暴露？ |
| 继承 | 表达 is-a 关系 | 子类是否真的可以替代父类？ |
| 组合 | 通过协作复用能力 | 是否比继承更容易变化？ |
| 多态 | 面向抽象调用 | 运行时实际执行哪个实现？ |

## 推荐复习顺序

先从类与对象开始，再连接封装、继承和多态，最后比较接口、抽象类与组合。复习 `equals` 时应同时检查 `hashCode` 契约。

## 快速自测

1. 重载和重写分别在什么时候确定调用目标？
2. 为什么“优先使用组合而不是继承”不是绝对规则？
3. 接口与抽象类分别更适合表达什么？
4. 为什么重写 `equals` 时通常也需要重写 `hashCode`？
