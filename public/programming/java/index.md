# Java 知识体系

这个主题汇总当前 Java 学习内容。它不是一份一次写完的教材，而是一张随着学习不断完善的复习地图。

## 模块入口

1. [Java 基础](fundamentals/index.md)：语言语法、类型、控制流程、方法与异常。
2. [面向对象](oop/index.md)：类与对象、封装、继承、多态、接口与抽象。
3. [Java Web](java-web/index.md)：HTTP、Servlet、会话状态和 Web 分层思想。
4. [Spring 核心](spring/index.md)：IoC、依赖注入、Bean、AOP 与 Spring MVC。
5. [Spring Boot](spring-boot/index.md)：自动配置、Web 开发、数据访问与测试。
6. [Spring Cloud](spring-cloud/index.md)：微服务拆分、服务治理与分布式系统基础设施。

## 如何复习

先浏览每个模块的核心概念和自测问题。遇到不能清楚解释的概念，再进入对应的详细笔记；没有详细笔记的项目表示仍待后续学习整理。
