# Java Web

本模块连接 Java 程序与 Web 请求，重点理解浏览器、HTTP 服务器和应用代码之间的数据流。

## 核心概念地图

- HTTP 请求、响应、方法、状态码与头部
- Servlet 生命周期和请求处理
- Request、Response 与参数转换
- Cookie、Session 与会话状态
- Filter、Listener 与横切处理
- MVC 分层思想

## 推荐复习顺序

先画出一次 HTTP 请求的完整路径，再分别复习 Servlet、会话状态和过滤器。进入 Spring MVC 前，应当能够解释传统 Servlet 模型解决了什么问题。

## 快速自测

1. HTTP 无状态意味着什么？
2. Cookie 与 Session 分别保存什么信息？
3. Filter 与 Servlet 的职责有什么差异？
4. MVC 为什么要分离请求处理、业务逻辑和页面表示？
